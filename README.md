\# Portfólio – Alessandra Krob

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript, criado para apresentar minha trajetória, habilidades técnicas e projetos desenvolvidos durante minha transição de carreira para a área de tecnologia.
